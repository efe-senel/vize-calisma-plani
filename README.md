# Vize Rotası — GitHub Pages

19 Ekim–8 Kasım 2026 tarihli kişisel vize çalışma planı. 7–8 Kasım son hafta sonu sınav sırasına göre esnek tekrar için ayrıldı.

## GitHub Pages'i etkinleştirme

1. Deponun **Settings → Pages** sayfasına gir.
2. **Build and deployment → Source** bölümünde **Deploy from a branch** seç.
3. **Branch:** `main`, **Folder:** `/(root)` seç ve **Save** bas.
4. GitHub Pages yayımlandığında site adresi: https://efe-senel.github.io/vize-calisma-plani/

## iPhone Safari

Siteyi Safari'de aç → Paylaş → Ana Ekrana Ekle.

## Veri gizliliği

Site kaynak kodu ve plandaki sabit bilgiler herkese açıktır. Sınav tarihlerin, görev işaretlerin ve kişisel notların yalnız tarayıcının yerel depolamasında saklanır. Başka cihazda otomatik olarak görünmez. Safari site verilerini silersen bu kayıtlar da silinebilir.

İlk çevrimiçi ziyaret sonrasında bazı tarayıcılarda çevrimdışı kullanım sağlanır.
